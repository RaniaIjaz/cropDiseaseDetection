# Crop Disease Detection Frontend

The Next.js interface for the Crop Disease Detection System. It provides English and Urdu experiences for authentication, wheat and cotton image analysis, prediction results, and report history.

## Development

Install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The FastAPI backend should be running at `http://localhost:8000`.

For complete setup instructions, architecture details, and environment variables, see the [project README](../README.md).
